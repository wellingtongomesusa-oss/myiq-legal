MyIQ Poster

MyIQ Poster is a private tool used only by its owner to publish short gaming clips to the owner's own accounts, Clutch Cuts and Lance Brabo, on YouTube, Instagram and TikTok, and to read those accounts' video statistics.

It is not offered to the public and does not accept other users.

Uses YouTube API Services
Uploads the owner's Shorts and reads the owner's channel statistics through the YouTube Data API and YouTube Analytics API. By using this tool you agree to the YouTube Terms of Service; see also the Google Privacy Policy.

What it does

  • Uploads the owner's finished clips to the owner's YouTube channels, with title, description and tags, scheduled at a set time.
  • Reads view, like and watch-time statistics of the owner's own videos to see which clips work best.
  • Does not access any other person's account or data.
